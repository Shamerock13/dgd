# Daten- und Duftzwilling-Recherche 1.0

Dieses Paket bündelt die redaktionelle Recherche über einen gemeinsamen Admin-Workflow.

Geplanter Ablauf:

1. vorhandene Düfte auf fehlende Angaben prüfen
2. für offene Datenlücken Rechercheaufträge erzeugen
3. mögliche Dubletten samt Quellenbelegen sammeln
4. im Netz ausdrücklich genannte Duftzwillinge als Vorschläge speichern
5. Ergebnisse ausschließlich nach redaktioneller Freigabe übernehmen

Der zentrale Admin-Button heißt **Daten & Duftzwillinge suchen**.

Sicherheits- und Qualitätsregeln:

- keine automatische Veröffentlichung neuer Düfte oder Duftzwillinge
- keine automatische Zusammenführung möglicher Dubletten
- mehrere Quellen pro Duftzwilling-Vorschlag möglich
- explizite Netz-Aussagen wie „inspired by“, „dupe“, „clone“ oder „alternative to“ werden als Beleg gespeichert
- algorithmische Ähnlichkeit darf ergänzen, ersetzt aber keine Quellenbelege
- unbekannte Alternativen werden als Importvorschlag behandelt
- private und interne Netzwerkziele bleiben gesperrt
